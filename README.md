# Fridgance

Fridgance is a responsive website for a refrigerator company, built using HTML5, CSS3, and JavaScript (with jQuery). The site showcases products, team members, weekly specials, and includes interactive features such as product search and a contact form.

## Features

- **Home Page:** Introduction to Fridgance and navigation to all sections.
- **About:** Company background and unique selling points.
- **Team:** Meet the team with interactive hover effects.
- **Products:** Dynamic product table loaded from `products.json`.
- **Specials:** Weekly sales with interactive image and caption swapping.
- **Search:** Search for refrigerator images using the Flickr API.
- **Contact:** Form with client-side validation for user inquiries.
- **Register:** Confirmation page after form submission.
- **Style Guide:** Reference for typography and color scheme.

## Directory Structure

```

```

- **css/**: Stylesheets for each section and overall layout.
- **images/**: Company logos, product images, and banners.
- **js/**: JavaScript files for interactivity and validation.
- **template/**: HTML template for consistent page structure.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser to view the homepage.
3. No build step is required; all resources are static.

## Dependencies

- [jQuery 3.1.1](https://code.jquery.com/jquery-3.1.1.min.js) (via CDN)
- [Flickr API](https://www.flickr.com/services/api/) for image search
